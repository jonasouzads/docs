<ParamField path="POST https://api.wizebot.com.br/api/v1/whatsapp/tags" />

Cria uma etiqueta. Responde `201 Created`.

A operação é idempotente pelo nome: se já existir etiqueta com o mesmo nome, nada é criado e a resposta continua sendo de sucesso.

## Parâmetros

<ParamField body="name" type="string" required>
  Nome da etiqueta.
</ParamField>

## Exemplo

```bash
curl -X POST 'https://api.wizebot.com.br/api/v1/whatsapp/tags' \
  -H 'Authorization: Bearer API-KEY' \
  -H 'Content-Type: application/json' \
  -d '{ "name": "Lead quente" }'
```

## Resposta

```json
{
  "success": true,
  "data": { "message": "Tag created successfully." },
  "timestamp": "2026-09-08T19:30:00.000Z"
}
```

<Warning>
  A resposta **não devolve o `id`** da etiqueta. Para usá-la em `tag_ids`, faça em seguida um [Listar etiquetas](/tutoriais/api/listar-etiquetas-whatsapp) e localize-a pelo nome.
</Warning>

<Note>
  Etiqueta criada por esta API não fica associada a nenhum número de WhatsApp específico. Em telas do painel que filtram etiquetas por número, ela pode não aparecer.
</Note>
