A API externa permite que o seu sistema envie mensagens de WhatsApp, consulte o status de entrega e gerencie contatos, etiquetas e campos personalizados da WizeBot.

## Antes de começar

Esta API tem limites que definem se ela serve para o seu caso. Vale conhecê-los antes de escrever a primeira linha de código.

<Warning>
  **Só é possível responder a conversas existentes.** O envio exige que o contato já tenha falado com o seu número antes. Não há como iniciar uma conversa pela API, porque o envio de modelo de mensagem não está disponível aqui. Veja [Enviar mensagem](/tutoriais/api/enviar-mensagem-whatsapp).
</Warning>

<Note>
  **É uma API de servidor para servidor.** A chave concede acesso total à sua conta e não pode ir para o navegador. Veja [Autenticação](/tutoriais/api/autenticacao-api-whatsapp).
</Note>

## URL base

Todos os endpoints ficam sob a mesma base:

```
https://api.wizebot.com.br/v1/whatsapp
```

<Note>
  Integrações que já usam `https://api.wizebot.com.br/api/v1/whatsapp` continuam funcionando, sem prazo de desligamento. Não é preciso migrar nada; a base acima é apenas mais curta.
</Note>

<Info>
  **Sobre o domínio antigo.** Versões anteriores desta documentação usavam `app.wizebot.com.br` nos exemplos. Aquele domínio **nunca serviu esta API** — ele responde apenas pelo painel, e as requisições ali sempre retornaram erro de rota não encontrada. Não existe transição de domínio a fazer nem prazo de desligamento: há apenas a base acima, que é a correta desde agora.
</Info>

## Obter uma chave

1. Acesse o painel da WizeBot.
2. Vá em **Configurações → API Keys**.
3. Clique em **Nova API Key**.
4. Copie a chave gerada — ela só é exibida uma vez.

<Warning>
  A chave é confidencial e dá acesso total à sua conta. Guarde-a em local seguro e nunca a coloque em código-fonte público, aplicativo móvel ou página web.
</Warning>

## Identificar o `phone_number_id`

A maioria dos endpoints exige o parâmetro `phone_number_id`, que identifica de qual dos seus números de WhatsApp a operação parte. É o identificador do número na Meta, e você o encontra no painel, na tela de conexão do WhatsApp.

## Primeira chamada

O endpoint de teste de conexão confirma que a chave funciona, sem produzir nenhum efeito:

```bash
curl 'https://api.wizebot.com.br/v1/whatsapp/ping' \
  -H 'Authorization: Bearer API-KEY'
```

Resposta:

```json
{
  "success": true,
  "data": {
    "message": "API Key is valid.",
    "tenant_id": "ef529f50-9fa6-4362-809f-f517e9ce5b56",
    "permissions": ["read"],
    "timestamp": "2026-09-08T19:30:00.000Z"
  },
  "timestamp": "2026-09-08T19:30:00.000Z"
}
```

<Note>
  O campo `permissions` é informativo. Ele **não restringe** o que a chave pode fazer nos endpoints do WhatsApp: qualquer chave válida pode ler e escrever.
</Note>

## O que existe nesta API

| Área | O que dá para fazer |
|---|---|
| Mensagens | Enviar texto e mídia, consultar status de entrega |
| Contatos | Listar, buscar, criar, atualizar, excluir |
| Etiquetas | Listar, criar, atribuir a um contato |
| Campos personalizados | Listar definições, gravar valores no contato |
| Modelos | Listar os modelos aprovados da conta |
| Sequências | Consultar e cancelar sequência agendada |
| Recebimento | Encaminhamento de mensagens recebidas para a sua URL |

## O que não existe

| Recurso | Situação |
|---|---|
| Envio de modelo de mensagem | Não disponível nesta API |
| Início de conversa com número novo | Depende do envio de modelo |
| Envio em lote | Uma mensagem por requisição |
| Chave de idempotência | Reenvio por timeout entrega duas mensagens |
| Histórico de conversa | Endpoint indisponível |
| Disparo de fluxo | Endpoint indisponível |
| Remoção de etiqueta do contato | Endpoint indisponível |
| Notificação de mudança de status | Só por consulta ao status |

## Suporte

Em caso de dúvida, escreva para [suporte@wizebot.com.br](mailto:suporte@wizebot.com.br). Se estiver relatando um erro, **inclua o campo `errorId`** da resposta: ele é o que permite localizar a requisição exata nos nossos registros.
