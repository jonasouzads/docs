<ParamField path="GET https://api.wizebot.com.br/api/v1/whatsapp/tags" />

Lista todas as etiquetas da empresa, em ordem alfabética.

<Note>
  Este endpoint não exige `phone_number_id`: etiquetas são da empresa, não de um número.
</Note>

## Exemplo

```bash
curl 'https://api.wizebot.com.br/api/v1/whatsapp/tags' \
  -H 'Authorization: Bearer API-KEY'
```

## Resposta

```json
{
  "success": true,
  "data": {
    "items": [
      { "id": "vip_1757280000000", "name": "VIP" },
      { "id": "cliente_1757280000001", "name": "Cliente" }
    ]
  },
  "timestamp": "2026-09-08T19:30:00.000Z"
}
```

<Note>
  É aqui que você obtém os `id` usados em `tag_ids` ao [atualizar um contato](/tutoriais/api/atualizar-assinante-whatsapp) ou [atribuir etiquetas](/tutoriais/api/etiquetas-do-contato-whatsapp).
</Note>
