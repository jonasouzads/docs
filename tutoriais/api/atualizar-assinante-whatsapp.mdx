<ParamField path="PATCH https://api.wizebot.com.br/v1/whatsapp/contacts" />

Atualiza os dados de um contato e, opcionalmente, atribui etiquetas.

## Parâmetros

<ParamField body="phone_number_id" type="string" required>
  Identificador do seu número de WhatsApp na Meta.
</ParamField>

<ParamField body="phone_number" type="string" required>
  Telefone do contato, com código do país e apenas dígitos.
</ParamField>

<ParamField body="first_name" type="string">
  Primeiro nome.
</ParamField>

<ParamField body="last_name" type="string">
  Sobrenome.
</ParamField>

<ParamField body="gender" type="string">
  Gênero. Texto livre, gravado como está.
</ParamField>

<ParamField body="tag_ids" type="string">
  Identificadores de etiqueta separados por vírgula. As etiquetas são **adicionadas**; nenhuma é removida.
</ParamField>

<Warning>
  `first_name` e `last_name` são concatenados num único campo de nome. Enviar apenas `last_name` substitui o nome inteiro pelo sobrenome.
</Warning>

## Exemplo

```bash
curl -X PATCH 'https://api.wizebot.com.br/v1/whatsapp/contacts' \
  -H 'Authorization: Bearer API-KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "phone_number_id": "119153661148976",
    "phone_number": "5511999999999",
    "first_name": "João",
    "last_name": "Silva",
    "tag_ids": "id-da-etiqueta-1,id-da-etiqueta-2"
  }'
```

## Resposta

```json
{
  "success": true,
  "data": { "message": "Contact updated successfully." },
  "timestamp": "2026-09-08T19:30:00.000Z"
}
```

<Note>
  Os identificadores de `tag_ids` são os `id` devolvidos por [Listar etiquetas](/tutoriais/api/listar-etiquetas-whatsapp) — não os nomes.
</Note>

## Erros

| HTTP | Código | Causa |
|---|---|---|
| 400 | `MISSING_PARAM` | Falta `phone_number` |
| 404 | `CHANNEL_NOT_FOUND` | `phone_number_id` não pertence à sua empresa |
| 404 | `CONTACT_NOT_FOUND` | Contato inexistente, ou telefone em formato diferente do gravado |
