<ParamField path="GET https://api.wizebot.com.br/api/v1/whatsapp/contacts" />

Lista os contatos vinculados a um dos seus números de WhatsApp.

## Parâmetros

<ParamField query="phone_number_id" type="string" required>
  Identificador do seu número de WhatsApp na Meta.
</ParamField>

<ParamField query="limit" type="number" default="20">
  Quantidade de contatos por página. Máximo de 100.
</ParamField>

<ParamField query="offset" type="number" default="0">
  Deslocamento para paginação.
</ParamField>

<Note>
  Não há filtro nem busca nesta listagem, e a resposta não informa o total de contatos. Para saber se chegou ao fim, pagine até receber uma página com menos itens que o `limit`.
</Note>

## Exemplo

```bash
curl 'https://api.wizebot.com.br/api/v1/whatsapp/contacts?phone_number_id=119153661148976&limit=20&offset=0' \
  -H 'Authorization: Bearer API-KEY'
```

## Resposta

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
        "phone_number": "5511999999999",
        "name": "João Silva",
        "email": "joao@exemplo.com",
        "gender": "male",
        "tag_names": "VIP,Cliente"
      }
    ],
    "limit": 20,
    "offset": 0
  },
  "timestamp": "2026-09-08T19:30:00.000Z"
}
```

<Note>
  `tag_names` vem como texto único com as etiquetas separadas por vírgula, não como lista. Etiqueta cujo nome contenha vírgula fica ambígua nesse formato.
</Note>

## Paginação estável

A paginação é por deslocamento. Se contatos forem criados durante a varredura, itens podem se repetir ou ser pulados entre páginas. Para varreduras longas, prefira percorrer do fim para o começo ou tolerar repetição no seu lado.

## Erros

| HTTP | Código | Causa |
|---|---|---|
| 400 | `MISSING_PARAM` | `phone_number_id` não informado |
| 404 | `CHANNEL_NOT_FOUND` | `phone_number_id` não pertence à sua empresa |
