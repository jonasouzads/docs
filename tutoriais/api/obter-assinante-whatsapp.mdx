<ParamField path="GET https://api.wizebot.com.br/api/v1/whatsapp/contacts/lookup" />

Busca um contato específico pelo telefone.

## Parâmetros

<ParamField query="phone_number_id" type="string" required>
  Identificador do seu número de WhatsApp na Meta.
</ParamField>

<ParamField query="phone_number" type="string" required>
  Telefone do contato, com código do país e apenas dígitos.
</ParamField>

<Warning>
  **A comparação é literal.** O telefone informado é comparado exatamente com o que está gravado. `+55 11 99999-8888` não encontra um contato salvo como `5511999998888`. Use sempre apenas dígitos, com código do país.
</Warning>

## Exemplo

```bash
curl 'https://api.wizebot.com.br/api/v1/whatsapp/contacts/lookup?phone_number_id=119153661148976&phone_number=5511999999999' \
  -H 'x-api-key: wz_live_sua_chave_aqui'
```

## Resposta

```json
{
  "success": true,
  "data": {
    "data": {
      "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
      "phone_number": "5511999999999",
      "name": "João Silva",
      "email": "joao@exemplo.com",
      "gender": "male",
      "tag_names": "VIP,Cliente"
    }
  },
  "timestamp": "2026-09-08T19:30:00.000Z"
}
```

## Erros

| HTTP | Código | Causa |
|---|---|---|
| 400 | `MISSING_PARAM` | Falta `phone_number` ou `phone_number_id` |
| 404 | `CHANNEL_NOT_FOUND` | `phone_number_id` não pertence à sua empresa |
| 404 | `CONTACT_NOT_FOUND` | Contato inexistente nesse número, ou telefone em formato diferente do gravado |
