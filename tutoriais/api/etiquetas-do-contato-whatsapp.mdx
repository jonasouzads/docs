<ParamField path="POST https://api.wizebot.com.br/api/v1/whatsapp/contacts/tags" />

Adiciona uma ou mais etiquetas a um contato. A operação é idempotente: etiqueta já atribuída não é duplicada.

<Warning>
  **A remoção de etiquetas está indisponível.** O endpoint correspondente falha em toda chamada e por isso não está documentado. Enquanto isso, para tirar uma etiqueta de um contato, use o painel.
</Warning>

## Parâmetros

<ParamField body="phone_number_id" type="string" required>
  Identificador do seu número de WhatsApp na Meta.
</ParamField>

<ParamField body="phone_number" type="string" required>
  Telefone do contato, com código do país e apenas dígitos.
</ParamField>

<ParamField body="tag_ids" type="string" required>
  Identificadores de etiqueta separados por vírgula, obtidos em [Listar etiquetas](/tutoriais/api/listar-etiquetas-whatsapp).
</ParamField>

## Exemplo

```bash
curl -X POST 'https://api.wizebot.com.br/api/v1/whatsapp/contacts/tags' \
  -H 'x-api-key: wz_live_sua_chave_aqui' \
  -H 'Content-Type: application/json' \
  -d '{
    "phone_number_id": "119153661148976",
    "phone_number": "5511999999999",
    "tag_ids": "vip_1757280000000,cliente_1757280000001"
  }'
```

## Resposta

```json
{
  "success": true,
  "data": { "message": "Tags assigned successfully." },
  "timestamp": "2026-09-08T19:30:00.000Z"
}
```

## Erros

| HTTP | Código | Causa |
|---|---|---|
| 400 | `MISSING_PARAM` | Falta `phone_number` ou `tag_ids` |
| 404 | `CHANNEL_NOT_FOUND` | `phone_number_id` não pertence à sua empresa |
| 404 | `CONTACT_NOT_FOUND` | Contato inexistente nesse número |
