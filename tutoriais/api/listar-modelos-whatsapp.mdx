<ParamField path="GET https://api.wizebot.com.br/v1/whatsapp/templates" />

Lista os modelos de mensagem cadastrados na empresa.

<Warning>
  **Não é possível enviar modelo por esta API.** Este endpoint apenas lista. O envio de mensagem aceita somente texto e mídia — veja [Enviar mensagem](/tutoriais/api/enviar-mensagem-whatsapp). Para disparar modelo, use campanhas ou fluxos no painel.
</Warning>

## Parâmetros

<ParamField query="phone_number_id" type="string">
  Aceito por compatibilidade, mas **ignorado**: a listagem é sempre de toda a empresa.
</ParamField>

## Exemplo

```bash
curl 'https://api.wizebot.com.br/v1/whatsapp/templates' \
  -H 'Authorization: Bearer API-KEY'
```

## Resposta

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "id": "b7e1c2d4-0000-4000-8000-000000000001",
        "template_id": "437509121867805",
        "template_name": "confirmacao_pedido",
        "template_type": "UTILITY",
        "locale": "pt_BR",
        "status": "APPROVED",
        "template_json": []
      }
    ]
  },
  "timestamp": "2026-09-08T19:30:00.000Z"
}
```

<Note>
  A listagem **não filtra por status**: modelos em `PENDING` e `REJECTED` vêm junto com os `APPROVED`. Só os aprovados podem ser usados em campanhas e fluxos — filtre por `status` no seu lado.
</Note>

| Campo | O que traz |
|---|---|
| `id` | Identificador do modelo na WizeBot |
| `template_id` | Identificador do modelo na Meta |
| `template_name` | Nome do modelo |
| `template_type` | Categoria: `UTILITY`, `MARKETING`, `AUTHENTICATION` |
| `locale` | Idioma, por exemplo `pt_BR` |
| `status` | `APPROVED`, `PENDING` ou `REJECTED` |
| `template_json` | Estrutura de componentes do modelo |
