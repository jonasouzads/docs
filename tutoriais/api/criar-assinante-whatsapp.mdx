<ParamField path="POST https://api.wizebot.com.br/api/v1/whatsapp/contacts" />

Cria um contato. Responde `201 Created`.

<Note>
  Criar um contato **não** habilita o envio de mensagem para ele. O envio continua exigindo que o contato tenha conversado com o seu número antes. Veja [Enviar mensagem](/tutoriais/api/enviar-mensagem-whatsapp).
</Note>

## Parâmetros

<ParamField body="phone_number_id" type="string" required>
  Identificador do seu número de WhatsApp na Meta.
</ParamField>

<ParamField body="phone_number" type="string" required>
  Telefone do contato, com código do país e apenas dígitos.
</ParamField>

<ParamField body="name" type="string" required>
  Nome do contato, em um único campo.
</ParamField>

<Note>
  A criação recebe o nome inteiro em `name`, enquanto a [atualização](/tutoriais/api/atualizar-assinante-whatsapp) recebe `first_name` e `last_name` separados. É uma assimetria da API: ao atualizar, os dois campos são concatenados no mesmo `name`.
</Note>

## Exemplo

```bash
curl -X POST 'https://api.wizebot.com.br/api/v1/whatsapp/contacts' \
  -H 'Authorization: Bearer API-KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "phone_number_id": "119153661148976",
    "phone_number": "5511999999999",
    "name": "João Silva"
  }'
```

## Resposta

```json
{
  "success": true,
  "data": { "message": "Contact created successfully." },
  "timestamp": "2026-09-08T19:30:00.000Z"
}
```

<Warning>
  A resposta **não devolve o `id`** do contato criado. Se precisar dele, faça em seguida uma [busca pelo telefone](/tutoriais/api/obter-assinante-whatsapp).
</Warning>

## Contato duplicado

O `409 CONTACT_EXISTS` é devolvido quando o telefone já pertence a um contato da sua empresa. A verificação considera variações de formatação do mesmo número, então `+55 11 99999-8888` e `5511999998888` são reconhecidos como o mesmo telefone.

## Erros

| HTTP | Código | Causa |
|---|---|---|
| 400 | `MISSING_PARAM` | Falta `phone_number` ou `name` |
| 403 | — | Limite de contatos do plano atingido |
| 404 | `CHANNEL_NOT_FOUND` | `phone_number_id` não pertence à sua empresa |
| 409 | `CONTACT_EXISTS` | Já existe contato com esse telefone |
